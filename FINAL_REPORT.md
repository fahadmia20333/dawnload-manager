## Browser integration and verification

- The installer build generates separate Chrome and Edge Native Messaging manifests and registry entries from `native-host/extension-origins.json`.
- The host manifest is limited to the configured browser extension ID. If a store assigns another ID, update that browser manifest's public signing key and the matching configured ID before rebuilding.
- A Native Messaging host ping to the running desktop returned protocol v2 `pong` with `desktopReady: true`.
- Isolated headless Chrome/Edge extension-load attempts did not expose the package's service worker, and direct extension-page navigation was blocked. Therefore, an actual browser-extension handshake and browser-download handoff are **not verified**.
- The extension was not found in the default Chrome or Edge profile. No existing browser profile was modified.
- A clean Windows 10/11 VM installation, launch, uninstall, and reinstall test was not available. The installer was built and its resource layout inspected, but was not run against this machine's existing Meldrix installation.

The installer registers the host but does not silently install browser extensions. Users must load the bundled matching Chrome or Edge folder manually until official store listings exist. Store approval, store-issued IDs, screenshots, and a public privacy-policy URL remain outstanding.

## S3 archive and release backend

No AWS CLI, S3 configuration, bucket URL, or credentials are available in this repository/environment, and `dawnloadmanager.zip` was not present in the local Downloads directory. The 1.1 GB remote object's contents and dependencies therefore could not be inspected. **No S3 object was deleted, and no removal recommendation is made without an object inventory and dependency review.**

This repository contains no public download website, admin release manager, or server-side S3 presigning backend. There is no verified public download URL to add. Do not expose AWS credentials or generate presigned URLs in the desktop app or browser.
